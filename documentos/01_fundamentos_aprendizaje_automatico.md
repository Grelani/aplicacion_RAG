# Fundamentos de aprendizaje automático

Material didáctico original para DocuChat AI. Su propósito es demostrar búsquedas semánticas; no describe resultados de investigaciones originales.

## ¿Qué es el aprendizaje automático?

El aprendizaje automático, o machine learning, es un área de la inteligencia artificial que construye modelos capaces de identificar patrones a partir de datos. En lugar de programar una regla explícita para cada posible caso, se entrena un modelo con ejemplos y después se utiliza para predecir o describir situaciones nuevas.

Un ejemplo es un filtro de correo no deseado. A partir de mensajes clasificados previamente, el modelo aprende patrones asociados con spam y los utiliza para clasificar correos posteriores.

## Aprendizaje supervisado

En aprendizaje supervisado, cada ejemplo de entrenamiento incluye una entrada y una etiqueta o valor objetivo conocido. El algoritmo intenta aprender una relación entre ambas partes. La clasificación y la regresión son dos tipos principales de tareas supervisadas.

En clasificación, la salida es una categoría: por ejemplo, decidir si una fotografía contiene un gato o un perro. En regresión, la salida es un valor numérico continuo: por ejemplo, estimar el precio de una casa en pesos.

## Aprendizaje no supervisado

En aprendizaje no supervisado, los datos no tienen etiquetas objetivo para la tarea. El sistema busca estructuras, grupos o relaciones en las observaciones. Un ejemplo es la agrupación de clientes según sus hábitos de compra mediante clustering.

## Aprendizaje por refuerzo

En aprendizaje por refuerzo, un agente interactúa con un entorno y aprende una política de acciones a partir de recompensas o penalizaciones. Se usa en problemas de toma de decisiones secuenciales.

## Generalización

Un modelo debe funcionar sobre datos que no vio durante el entrenamiento. Si memoriza demasiado las particularidades del conjunto de entrenamiento, puede presentar sobreajuste. Si es demasiado simple y no captura patrones relevantes, puede presentar subajuste.

La generalización se evalúa con datos separados de los empleados para ajustar el modelo.
